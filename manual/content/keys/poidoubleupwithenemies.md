---
key: POIDoubleUpWithEnemies
summary: Allows matching neutral-owned point-of-interest requests from enemies to share one structure.
when_omitted:
  kind: value
  value: "no"
---

Allows this house's neutral-owned request to merge with an enemy's reciprocal fractional-location request when both request the same structure between the same starts and both requests are neutral-owned. Either house can enable sharing. Player-owned requests cannot share with enemies. Use [`POIDoubleUpWithAllies`](/keys/poidoubleupwithallies/) to enable sharing with allies. [Points of interest](/systems/points-of-interest/) describes the matching rules and placement checks.
